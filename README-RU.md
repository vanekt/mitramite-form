# Unofficial Mitramite Status Form

[EN](README.md) | [ES](README-ES.md) | **RU**

**Установите расширение, откройте https://mitramite.renaper.gob.ar/ — и форма проверки снова появится.**

Расширение для Chrome, которое возвращает форму проверки статуса заявки на https://mitramite.renaper.gob.ar/. Оригинальная форма на сайте больше не отображается, но сервис проверки продолжает работать; расширение снова добавляет форму и показывает этапы процесса, текущий статус и историю движения.

**Не связано с RENAPER и правительством Аргентины и не согласовано с ними.**

![Скриншот](docs/screenshot.jpg)

## Возможности

- Форма на странице: введите номер заявки и посмотрите её статус.
- Этапы процесса (Inicio, Verificación, Producción, Embalaje, Correo), текущий и предыдущий статус, способ доставки, офис и дата подачи.
- Полная история движения, включая события почты.
- Запоминает проверенные номера и подсказывает их при фокусе на поле; пока вы не выберете номер, ничего не запрашивается.
- Обновление одним нажатием, адаптивная вёрстка для маленьких окон.
- Интерфейс на испанском, как и сам сайт.

## Установка

[**Установить из Chrome Web Store**](https://chromewebstore.google.com/detail/unofficial-mitramite-stat/afjbckgljnnaimdckbgaigfjnnmlobai) или установите вручную из ZIP, как описано ниже.

### Из ZIP

1. Скачайте `mitramite-form-<версия>.zip` из [последнего релиза](https://github.com/vanekt/mitramite-form/releases/latest) и распакуйте в папку, которую вы сохраните (потом её нельзя удалять и перемещать).
2. Откройте `chrome://extensions` и включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение** и выберите распакованную папку.

Работает в Chrome 111+ и других браузерах на Chromium. При запуске Chrome может показывать предупреждение о расширениях в режиме разработчика, а расширения, установленные так, не обновляются автоматически.

## Использование

Установите расширение, затем откройте https://mitramite.renaper.gob.ar/, введите номер заявки и нажмите кнопку.

## Конфиденциальность

Расширение отправляет введённый номер на собственный сервис проверки сайта, как и оригинальная форма, и больше ничего не собирает. Сохранённые номера остаются в локальном хранилище вашего браузера для этого сайта, и их можно удалить из списка подсказок. См. [PRIVACY.md](PRIVACY.md) (на английском).
